Safa Hop Inventory - Android Studio project

1. Install Android Studio (free) and open this folder (SafaHopInventory).
2. Wait for Gradle sync to finish (needs internet the first time).
3. Build > Build Bundle(s) / APK(s) > Build APK(s).
4. The APK is at app/build/outputs/apk/debug/app-debug.apk. Copy it to your phone and install it
   (allow "install unknown apps" if asked).

To update the data later, replace app/src/main/assets/index.html with a new export and rebuild.

NO ANDROID STUDIO? Build online for free:
1. Create a free GitHub account and a new repository.
2. Upload ALL files of this folder (including the hidden .github folder) to the repository.
3. Open the Actions tab > "Build APK" > wait ~3 minutes until green.
4. Open the finished run and download "SafaHop-Inventory-APK" - unzip it to get app-debug.apk.
